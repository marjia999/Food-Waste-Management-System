# Data Flow Diagram (DFD)

This folder contains the Data Flow Diagrams (DFD) for the Food Waste Management System project.

## Files

- **DFD Level 0** – Context diagram of the overall system
- **DFD Level 1** – Main processes and data flow
- **DFD Level 2** – Detailed breakdown of internal processes

These diagrams represent the flow of data between users, processes, and the system database.
